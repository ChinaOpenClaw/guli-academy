`.drawio` 为源文件，**可用 [draw.io（diagrams.net）](https://app.diagrams.net) 打开编辑，亿图图示亦可导入**；
同名 `.svg` 为预览图。

| 源文件 | 预览 | 内容 |
|---|---|---|
| `drawio/微服务架构.drawio` | [`drawio/微服务架构.svg`](./drawio/微服务架构.svg) | 前端 → 代理 → 微服务 → Eureka → MySQL/Redis/阿里云 |
| `drawio/数据库ER图.drawio` | [`drawio/数据库ER图.svg`](./drawio/数据库ER图.svg) | guli_edu 六表 ER 关系（字段级） |
| `drawio/部署拓扑图.drawio` | [`drawio/部署拓扑图.svg`](./drawio/部署拓扑图.svg) | Nginx + 静态包 + 微服务 + 数据库的单机部署拓扑 |

| 文件 | 内容 |
