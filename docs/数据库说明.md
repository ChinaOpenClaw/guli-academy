# 数据库说明

谷粒学院后端共 **3 个 MySQL 业务库**，建表与初始数据在 `sql/` 目录：

| 数据库 | 服务 | 表 | 说明 |
|---|---|---|---|
| `guli_edu` | guli-microservice-edu | `edu_teacher`、`edu_course`、`edu_course_description`、`edu_chapter`、`edu_video`、`edu_subject` | 课程域核心：讲师、课程、课程描述、章节、课时、课程分类 |
| `guli_ucenter` | guli-microservice-ucenter | `ucenter_member` | 用户域：会员/注册用户 |
| `guli_statistics` | guli-microservice-statistics | `statistics_daily` | 统计域：每日统计 |

初始数据量（`sql/*.sql`）：讲师 10 条、课程 7 门、章节 9 个、课时 4 个、分类 18 个（含二级）。

## 1. 五分钟初始化

```bash
# 1) 建库与账号（root 登录你的 MySQL）
mysql -u root -p <<'SQL'
CREATE DATABASE guli_edu        CHARACTER SET utf8mb4;
CREATE DATABASE guli_ucenter    CHARACTER SET utf8mb4;
CREATE DATABASE guli_statistics CHARACTER SET utf8mb4;
CREATE USER 'guli'@'%' IDENTIFIED BY 'guli';
CREATE USER 'guli'@'localhost' IDENTIFIED BY 'guli';
GRANT ALL PRIVILEGES ON guli_edu.*        TO 'guli'@'%';
GRANT ALL PRIVILEGES ON guli_ucenter.*    TO 'guli'@'%';
GRANT ALL PRIVILEGES ON guli_statistics.* TO 'guli'@'%';
GRANT ALL PRIVILEGES ON guli_edu.*        TO 'guli'@'localhost';
GRANT ALL PRIVILEGES ON guli_ucenter.*    TO 'guli'@'localhost';
GRANT ALL PRIVILEGES ON guli_statistics.* TO 'guli'@'localhost';
FLUSH PRIVILEGES;
SQL

# 2) 导入（SQL 文件无 USE 语句，命令行指定库名）
mysql -u guli -pguli guli_edu        < sql/guli_edu.sql
mysql -u guli -pguli guli_ucenter    < sql/guli_ucenter.sql
mysql -u guli -pguli guli_statistics < sql/guli_statistics.sql
```

## 2. 数据源配置（edu 微服务）

`guli-microservice-edu/src/main/resources/application.properties`：

```properties
spring.datasource.driver-class-name=com.mysql.cj.jdbc.Driver
spring.datasource.url=jdbc:mysql://localhost:3307/guli_edu?characterEncoding=utf-8&useSSL=false&allowPublicKeyRetrieval=true&serverTimezone=Asia/Shanghai
spring.datasource.username=guli
spring.datasource.password=guli
```

> 端口与账号按你的环境调整；本文示例统一使用 `guli/guli`，端口 `3307`。

## 3. MySQL 8/9 驱动兼容性（重要）

本项目 Spring Boot 版本为 **2.0.7**，其 `spring-boot-dependencies` BOM 会把
`mysql-connector-java` 解析到 **5.1.47**——该版本不支持 MySQL 8+ 的
`caching_sha2_password` 认证，连接时报
`Client does not support authentication protocol requested by server`。

**修复方式**（已在本仓库应用）：在 `guli-microservice-edu/pom.xml` 显式指定驱动版本：

```xml
<dependency>
    <groupId>mysql</groupId>
    <artifactId>mysql-connector-java</artifactId>
    <version>8.0.33</version>
</dependency>
```

配合 URL 上的 `allowPublicKeyRetrieval=true`，可在非 SSL 下完成 RSA 握手。

## 4. 使用独立 MySQL 实例（端口 3307，推荐）

如果本机 3306 已被其它项目占用，可为谷粒学院起一个独立实例，与系统 MySQL 互不干扰：

```bash
# 初始化数据目录（仅首次）
/opt/homebrew/opt/mysql/bin/mysqld --initialize-insecure --datadir=/opt/homebrew/var/mysql-dev

# 用仓库提供的示例配置启动（把 user 改成你的用户名）
/opt/homebrew/opt/mysql/bin/mysqld --defaults-extra-file=/tmp/mysql-dev.cnf
```

示例配置见 [`config/mysql-dev-3307.example.cnf`](../config/mysql-dev-3307.example.cnf)，
端口 3307、socket `/tmp/mysql-dev.sock`，之后即可按本文第 1 节建库导数据。

## 5. 表关系速览

```
edu_subject (分类，二级树)
   │
   └──< edu_course (课程) >── teacher_id ──> edu_teacher (讲师)
            │
            ├──< edu_chapter (章节) >──< edu_video (课时)
            └── 1:1 edu_course_description (课程详情，大文本)
```

- `edu_course.teacher_id` → `edu_teacher.id`（多对一）
- `edu_course.subject_id` → `edu_subject.id`（多对一，分类树）
- `edu_chapter.course_id` → `edu_course.id`（一对多）
- `edu_video.chapter_id` → `edu_chapter.id`（一对多）
- `edu_course.id` ↔ `edu_course_description.id`（一对一共享主键）

详细的图形化 ER 图见 [`drawio/数据库ER图.drawio`](./drawio/数据库ER图.drawio)（可用 draw.io / 亿图图示打开）。

## 6. MyBatis-Plus 映射

- 实体：`com.guli.edu.entity.*`（`@TableName` 对应上表）
- Mapper XML：`classpath:com/guli/edu/mapper/xml/*.xml`（`application.properties` 中 `mybatis-plus.mapper-locations`）
- 逻辑删除：`edu_teacher` 等表无 `deleted` 字段，走物理删除；统计库有软删字段以表结构为准。
