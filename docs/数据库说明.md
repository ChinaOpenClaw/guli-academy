# 数据库说明

MAD网课系统后端共 **3 个 MySQL 业务库**，建表与初始数据在 `sql/` 目录：

| 数据库 | 服务 | 表 | 说明 |
|---|---|---|---|
| `mad_edu` | mad-microservice-edu | `edu_teacher`、`edu_course`、`edu_course_description`、`edu_chapter`、`edu_video`、`edu_subject` | 课程域核心：讲师、课程、课程描述、章节、课时、课程分类 |
| `mad_ucenter` | mad-microservice-ucenter | `ucenter_member` | 用户域：会员/注册用户 |
| `mad_statistics` | mad-microservice-statistics | `statistics_daily` | 统计域：每日统计 |

初始数据量（`sql/*.sql`）：

| 数据 | 数量 | 说明 |
|---|---|---|
| 讲师 | **14** | 金融投资 8 位 + IT 工程 6 位，全部为真实领域名师 |
| 课程 | **16** | 金融投资 6 + IT 工程 7 + 人工智能 3 |
| 章节 | **88** | 每门课程 3–6 章 |
| 课时 | **395** | 全部绑定真实 YouTube 播放列表 / B 站 BV 号 |
| 分类 | **20** | 3 个一级分类 + 17 个二级分类 |

> 课程 `id` 与前端 `frontend/mad-portal/src/data/courses.js` 的 `id` **严格对齐（1–16）**，
> 这样门户学习中心的 `GET /edu/chapter/nested-list/{courseId}` 才能直接命中。
> 修改课程数据请改 `scripts/mad_data.py` 单一数据源，再执行 `scripts/gen_mad_assets.py` 重新生成。

## 1. 五分钟初始化

```bash
# 1) 建库与账号（root 登录你的 MySQL）
mysql -u root -p <<'SQL'
CREATE DATABASE mad_edu        CHARACTER SET utf8mb4;
CREATE DATABASE mad_ucenter    CHARACTER SET utf8mb4;
CREATE DATABASE mad_statistics CHARACTER SET utf8mb4;
CREATE USER 'mad'@'%' IDENTIFIED BY 'mad';
CREATE USER 'mad'@'localhost' IDENTIFIED BY 'mad';
GRANT ALL PRIVILEGES ON mad_edu.*        TO 'mad'@'%';
GRANT ALL PRIVILEGES ON mad_ucenter.*    TO 'mad'@'%';
GRANT ALL PRIVILEGES ON mad_statistics.* TO 'mad'@'%';
GRANT ALL PRIVILEGES ON mad_edu.*        TO 'mad'@'localhost';
GRANT ALL PRIVILEGES ON mad_ucenter.*    TO 'mad'@'localhost';
GRANT ALL PRIVILEGES ON mad_statistics.* TO 'mad'@'localhost';
FLUSH PRIVILEGES;
SQL

# 2) 导入（SQL 文件无 USE 语句，命令行指定库名）
mysql -u mad -pmad mad_edu        < sql/mad_edu.sql
mysql -u mad -pmad mad_ucenter    < sql/mad_ucenter.sql
mysql -u mad -pmad mad_statistics < sql/mad_statistics.sql
```

导入后校验：

```bash
mysql -u mad -pmad mad_edu -e "
SELECT '讲师' t, COUNT(*) n FROM edu_teacher
UNION ALL SELECT '课程', COUNT(*) FROM edu_course
UNION ALL SELECT '章节', COUNT(*) FROM edu_chapter
UNION ALL SELECT '课时', COUNT(*) FROM edu_video
UNION ALL SELECT '分类', COUNT(*) FROM edu_subject;"
# 期望：14 / 16 / 88 / 395 / 20
```

## 2. 数据源配置（edu 微服务）

`backend/mad/mad-microservice-edu/src/main/resources/application.properties`：

```properties
spring.datasource.driver-class-name=com.mysql.cj.jdbc.Driver
spring.datasource.url=jdbc:mysql://localhost:3307/mad_edu?characterEncoding=utf-8&useSSL=false&allowPublicKeyRetrieval=true&serverTimezone=Asia/Shanghai
spring.datasource.username=mad
spring.datasource.password=mad
```

> 端口与账号按你的环境调整；本文示例统一使用 `mad/mad`，端口 `3307`。

## 3. MySQL 8/9 驱动兼容性（重要）

本项目 Spring Boot 版本为 **2.0.7**，其 `spring-boot-dependencies` BOM 会把
`mysql-connector-java` 解析到 **5.1.47**——该版本不支持 MySQL 8+ 的
`caching_sha2_password` 认证，连接时报
`Client does not support authentication protocol requested by server`。

**修复方式**（已在本仓库应用）：在 `mad-microservice-edu/pom.xml` 显式指定驱动版本：

```xml
<dependency>
    <groupId>mysql</groupId>
    <artifactId>mysql-connector-java</artifactId>
    <version>8.0.33</version>
</dependency>
```

配合 URL 上的 `allowPublicKeyRetrieval=true`，可在非 SSL 下完成 RSA 握手。

## 4. 使用独立 MySQL 实例（端口 3307，推荐）

如果本机 3306 已被其它项目占用，可为 MAD网课系统起一个独立实例，与系统 MySQL 互不干扰：

```bash
# 初始化数据目录（仅首次）
/opt/homebrew/opt/mysql/bin/mysqld --initialize-insecure --datadir=/opt/homebrew/var/mysql-dev

# 用仓库提供的示例配置启动（把 user 改成你的用户名）
/opt/homebrew/opt/mysql/bin/mysqld --defaults-extra-file=/tmp/mysql-dev.cnf --daemonize
```

示例配置见 [`config/mysql-dev-3307.example.cnf`](../config/mysql-dev-3307.example.cnf)，
端口 3307、socket `/tmp/mysql-dev.sock`，之后即可按本文第 1 节建库导数据。

## 5. 表关系速览

```
edu_subject (分类，二级树)
   │
   └──< edu_course (课程) >── teacher_id ──> edu_teacher (讲师)
            │
            ├──< edu_chapter (章节) >──< edu_video (课时)
            └── 1:1 edu_course_description (课程详情，大文本)
```

- `edu_course.teacher_id` → `edu_teacher.id`（多对一）
- `edu_course.subject_id` → `edu_subject.id`（多对一，分类树）
- `edu_chapter.course_id` → `edu_course.id`（一对多）
- `edu_video.chapter_id` → `edu_chapter.id`（一对多）
- `edu_course.id` ↔ `edu_course_description.id`（一对一共享主键）

### `edu_video.video_source_id` 编码约定

播放来源用前缀区分平台，前台播放器据此路由：

| 前缀 | 示例 | 含义 |
|---|---|---|
| `YT:` | `YT:PL8FB14A2200B87185` | YouTube 播放列表 ID，序号由章节内课时顺序推算 |
| `BI:` | `BI:BV1qK4y1p7wG` | B 站 BV 号，分P 由章节内课时顺序推算 |

详细的图形化 ER 图见 [`drawio/数据库ER图.drawio`](./drawio/数据库ER图.drawio)（可用 draw.io / 亿图图示打开）。

## 6. MyBatis-Plus 映射

- 实体：`com.mad.edu.entity.*`（`@TableName` 对应上表）
- Mapper XML：`classpath:com/mad/edu/mapper/xml/*.xml`（`application.properties` 中 `mybatis-plus.mapper-locations`）
- 逻辑删除：`edu_teacher` 等表无 `deleted` 字段，走物理删除；统计库有软删字段以表结构为准。
