# 本地部署指南

> 环境要求：**JDK 8+（已在 JDK 17 上验证）**、Node 16（后台管理）、Node 20+（前台门户）、MySQL 5.7+/8.0/9.x、Maven 3.6+。
> 不想装 MySQL？见第 4 节「轻量演示后端」，用 Node 即可联调前台门户。

## 1. 数据库准备

建库、建账号与导入命令详见 [`数据库说明.md`](./数据库说明.md)（五分钟初始化）。
SQL 脚本在本仓库 `sql/` 目录：

```bash
# 快速版（root 登录 MySQL 后执行）
CREATE DATABASE mad_edu DEFAULT CHARACTER SET utf8mb4;
CREATE USER 'mad'@'%' IDENTIFIED BY 'mad';
GRANT ALL PRIVILEGES ON mad_edu.* TO 'mad'@'%';

mysql -u mad -pmad mad_edu < sql/mad_edu.sql
```

`application.properties` 中 JDBC 示例（MySQL 8/9 需 `allowPublicKeyRetrieval=true` 与 `com.mysql.cj.jdbc.Driver`）：

```properties
spring.datasource.url=jdbc:mysql://localhost:3307/mad_edu?serverTimezone=GMT%2B8&useSSL=false&allowPublicKeyRetrieval=true
spring.datasource.username=mad
spring.datasource.password=mad
```

> ⚠️ **MySQL 8/9 必读**：本项目 Spring Boot 2.0.7 的 BOM 会把
> `mysql-connector-java` 解析到 5.1.47，连不上 MySQL 8+（`caching_sha2_password`）。
> 已在 `mad-microservice-edu/pom.xml` 显式钉到 **8.0.33**，详见
> [`数据库说明.md`](./数据库说明.md) 第 3 节。

## 2. 启动后端微服务

建议启动顺序：注册中心 → 业务服务。

```bash
cd backend/mad

# 注册中心
mvn -pl mad-commonservice-eureka -am spring-boot:run

# 课程等核心业务（需 MySQL）
mvn -pl mad-microservice-edu -am spring-boot:run
mvn -pl mad-microservice-sysuser -am spring-boot:run

# 视频点播（需配置阿里云 VOD 密钥，见 docs/SDK配置.md）
mvn -pl mad-microservice-vod -am spring-boot:run

# 可选：oss / ucenter / statistics
mvn -pl mad-microservice-oss -am spring-boot:run
mvn -pl mad-microservice-ucenter -am spring-boot:run
mvn -pl mad-microservice-statistics -am spring-boot:run
```

> Web 管理后台访问各服务 Swagger：`http://localhost:<port>/swagger-ui.html`
> 默认端口：eureka 8220、edu 8110、sysuser 8120、vod 8160、oss 8002 等（以各 `application.properties` 为准）。

### 2.1 JDK 17 兼容（必需）

Spring Boot 2.0.7 在 JDK 17 上有两处硬伤，仓库已全部处理：

| 问题 | 现象 | 处理方式 |
|---|---|---|
| **CGLIB 反射受限** | `InaccessibleObjectException: module java.base does not "opens java.lang"` | 运行时加 `--add-opens java.base/java.lang=ALL-UNNAMED` 等 12 个参数 |
| **JAXB 被移除** | `ClassNotFoundException: javax.xml.bind.JAXBContext` | `mad-commonservice-eureka/pom.xml` 补 `jaxb-api:2.3.1` + `jaxb-impl:2.3.2` + `javax.activation-api:1.2.0` + `istack-commons-runtime:3.0.11` |

另有 **Lombok 与 JDK 17 编译器冲突**（`Unable to make field ... JavacProcessingEnvironment.discoveredProcs accessible`），
编译期需在 `MAVEN_OPTS` 中加：

```bash
export MAVEN_OPTS="--add-opens jdk.compiler/com.sun.tools.javac.api=ALL-UNNAMED \
 --add-opens jdk.compiler/com.sun.tools.javac.file=ALL-UNNAMED \
 --add-opens jdk.compiler/com.sun.tools.javac.main=ALL-UNNAMED \
 --add-opens jdk.compiler/com.sun.tools.javac.model=ALL-UNNAMED \
 --add-opens jdk.compiler/com.sun.tools.javac.parser=ALL-UNNAMED \
 --add-opens jdk.compiler/com.sun.tools.javac.processing=ALL-UNNAMED \
 --add-opens jdk.compiler/com.sun.tools.javac.tree=ALL-UNNAMED \
 --add-opens jdk.compiler/com.sun.tools.javac.util=ALL-UNNAMED \
 --add-opens jdk.compiler/com.sun.tools.javac.code=ALL-UNNAMED \
 --add-opens jdk.compiler/com.sun.tools.javac.comp=ALL-UNNAMED"
```

**推荐：直接用内置脚本**，全部参数已内置：

```bash
bash scripts/start_backend.sh all        # 一键启动 eureka + edu + sysuser
bash scripts/start_backend.sh eureka    # 只启注册中心
bash scripts/start_backend.sh edu       # 只启课程服务
```

### 2.2 日志路径

各服务 `logback-spring.xml` 已从硬编码的 Windows 路径（`D:/mad_log_190105/...`）改为
`${mad.log.path}`，可用环境变量覆盖：

```bash
export MAD_LOG_PATH=/tmp/mad_log_190105   # 默认值
```

> 若不改日志路径，macOS / Linux 上会因无法创建 `D:/` 目录导致服务启动即退出。

## 3. 启动前端

```bash
# 后台管理（Node 16）
cd frontend/mad-admin
npm install --legacy-peer-deps
NODE_OPTIONS=--openssl-legacy-provider npm run dev    # http://localhost:9528

# 前台门户（Node 20+）
cd frontend/mad-portal
npm install
npm run dev            # http://localhost:9529
```

> ⚠️ **`NODE_OPTIONS=--openssl-legacy-provider` 是必需的**：webpack 4 在 Node 17+ 的 OpenSSL 3 下会抛
> `error:0308010C:digital envelope routines::unsupported`，导致 dev server 秒退。

前端通过 dev server 代理把 `/admin/edu`、`/edu`、`/admin/sysuser` 转发到对应后端端口
（见 `frontend/mad-admin/config/index.js` 与 `frontend/mad-portal/vite.config.js`）。

### 3.1 静态资源路径

后台与前台的课程封面、讲师头像统一以 `/photo/...` 绝对路径访问：

| 位置 | 开发 | 生产 |
|---|---|---|
| `frontend/mad-portal/public/photo/` | Vite 自动挂载到 `/photo` | 打包进 `dist/photo` |
| `frontend/mad-admin/static/photo/` | `contentBase` 挂载到 `/photo` | `CopyWebpackPlugin` 拷到 `dist/photo` |

> 改这两个目录的图片时，两个前端要同步，否则后台列表封面会裂图。

## 4. 轻量演示后端（无需 MySQL）

`backend/learn-center` 是一个 Node 服务，提供与 edu 微服务**同款契约**的章节大纲接口，
数据复用前台门户的 `courses.js`，适合本地快速联调门户：

```bash
cd backend/learn-center
PORT=8111 node server.mjs    # 暴露 GET /edu/chapter/nested-list/{courseId}
```

将前台门户的章节接口指向 `http://localhost:8111` 即可（门户默认即走该契约）。

> ⚠️ **端口冲突提醒**：learn-center 默认端口也是 8110，与 edu 微服务相同。
> 二者**不要同时启动**——若后台管理出现「接口通了但数据是 demo 文案」，
> 多半是 Node 版 learn-center 抢占了 8110（macOS 上 Java 绑 IPv6、Node 抢 IPv4，
> `curl 127.0.0.1` 会落到 Node 进程）。需要真实数据时，先停掉 learn-center，
> 或如上例用 `PORT=8111` 错开。

## 5. 统一数据源与资源再生

课程 / 讲师 / 分类 / 章节的**唯一真源**是 `scripts/mad_data.py`。修改后重新生成
前端 JS、图片素材与数据库 SQL：

```bash
python3 scripts/gen_mad_assets.py
# 产出：
#   frontend/mad-portal/src/data/{teachers,courses,subjects}.js
#   frontend/mad-portal/public/photo/course/01..16.jpg
#   frontend/mad-portal/public/photo/teacher/01..14.jpg
#   sql/mad_edu.sql
```

> 生成后需同步图片到后台：`cp frontend/mad-portal/public/photo/course/*.jpg frontend/mad-admin/static/photo/course/`

## 6. 构建产物

```bash
cd frontend/mad-portal && npm run build   # 产出 dist/
cd frontend/mad-admin  && npm run build   # 产出 dist/
```

构建结果可静态托管，或交由 Nginx 统一对外提供，并反向代理后端微服务。

## 7. 服务健康检查

```bash
# 注册中心
curl http://localhost:8220/eureka/apps
# 课程服务（后台列表数据源）
curl http://localhost:8110/admin/edu/teacher
curl http://localhost:8110/admin/edu/course/1/8
curl http://localhost:8110/edu/chapter/nested-list/1
# 登录
curl -X POST http://localhost:8120/admin/sysuser/login \
  -H 'Content-Type: application/json' \
  -d '{"username":"admin","password":"admin"}'
```

> 沙箱 / 内网环境下 curl 访问本机端口需加 `--noproxy '*'`，否则会被代理拦截返回 502。
