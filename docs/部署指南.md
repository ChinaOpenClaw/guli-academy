# 本地部署指南

> 环境要求：JDK 8、Node 16（后台管理）、Node 20+（前台门户）、MySQL 5.7+/8.0/9.x、Maven 3.6+。
> 不想装 MySQL？见第 4 节「轻量演示后端」，用 Node 即可联调前台门户。

## 1. 数据库准备

建库、建账号与导入命令详见 [`数据库说明.md`](./数据库说明.md)（五分钟初始化）。
SQL 脚本在本仓库 `sql/` 目录：

```bash
# 快速版（root 登录 MySQL 后执行）
CREATE DATABASE guli_edu DEFAULT CHARACTER SET utf8mb4;
CREATE USER 'guli'@'%' IDENTIFIED BY 'guli';
GRANT ALL PRIVILEGES ON guli_edu.* TO 'guli'@'%';

mysql -u guli -pguli guli_edu < sql/guli_edu.sql
```

`application.properties` 中 JDBC 示例（MySQL 8/9 需 `allowPublicKeyRetrieval=true` 与 `com.mysql.cj.jdbc.Driver`）：

```properties
spring.datasource.url=jdbc:mysql://localhost:3307/guli_edu?serverTimezone=GMT%2B8&useSSL=false&allowPublicKeyRetrieval=true
spring.datasource.username=guli
spring.datasource.password=guli
```

> ⚠️ **MySQL 8/9 必读**：本项目 Spring Boot 2.0.7 的 BOM 会把
> `mysql-connector-java` 解析到 5.1.47，连不上 MySQL 8+（`caching_sha2_password`）。
> 已在 `guli-microservice-edu/pom.xml` 显式钉到 **8.0.33**，详见
> [`数据库说明.md`](./数据库说明.md) 第 3 节。

## 2. 启动后端微服务

建议启动顺序：注册中心 → 业务服务。

```bash
cd backend/guli

# 注册中心
mvn -pl guli-commonservice-eureka -am spring-boot:run

# 课程等核心业务（需 MySQL）
mvn -pl guli-microservice-edu -am spring-boot:run
mvn -pl guli-microservice-sysuser -am spring-boot:run

# 视频点播（需配置阿里云 VOD 密钥，见 docs/SDK配置.md）
mvn -pl guli-microservice-vod -am spring-boot:run

# 可选：oss / ucenter / statistics
mvn -pl guli-microservice-oss -am spring-boot:run
mvn -pl guli-microservice-ucenter -am spring-boot:run
mvn -pl guli-microservice-statistics -am spring-boot:run
```

> Web 管理后台访问各服务 Swagger：`http://localhost:<port>/swagger-ui.html`
> 默认端口：eureka 8220、edu 8110、sysuser 8120、vod 8160、oss 8002 等（以各 `application.properties` 为准）。

## 3. 启动前端

```bash
# 后台管理（Node 16）
cd frontend/guli-admin
npm install --legacy-peer-deps
npm run dev            # http://localhost:9528

# 前台门户（Node 20+）
cd frontend/guli-portal
npm install
npm run dev            # http://localhost:9529
```

前端通过 dev server 代理把 `/admin/edu`、`/edu`、`/admin/vod` 转发到对应后端端口
（见 `frontend/guli-admin/config/index.js` 与 `frontend/guli-portal/vite.config.*`）。

## 4. 轻量演示后端（无需 MySQL）

`backend/learn-center` 是一个 Node 服务，提供与 edu 微服务**同款契约**的章节大纲接口，
数据复用前台门户的 `courses.js`，适合本地快速联调门户：

```bash
cd backend/learn-center
PORT=8111 node server.mjs    # 暴露 GET /edu/chapter/nested-list/{courseId}
```

将前台门户的章节接口指向 `http://localhost:8111` 即可（门户默认即走该契约）。

> ⚠️ **端口冲突提醒**：learn-center 默认端口也是 8110，与 edu 微服务相同。
> 二者**不要同时启动**——若后台管理出现「接口通了但数据是 demo 文案」，
> 多半是 Node 版 learn-center 抢占了 8110（macOS 上 Java 绑 IPv6、Node 抢 IPv4，
> `curl 127.0.0.1` 会落到 Node 进程）。需要真实数据时，先停掉 learn-center，
> 或如上例用 `PORT=8111` 错开。

## 5. 构建产物

```bash
cd frontend/guli-portal && npm run build   # 产出 dist/
cd frontend/guli-admin  && npm run build    # 产出 dist/
```

构建结果可静态托管，或交由 Nginx 统一对外提供，并反向代理后端微服务。
